# Emotional World

## 项目简介

Emotional World 是一个基于情绪识别、三层记忆和世界状态的智能 Agent 系统，旨在为用户带来更真实、更有温度的交互体验。

## 三个场景

### 1. 客服场景
- **功能**：智能处理咨询、售后和问题定位
- **特点**：专业、高效的客户服务体验
- **入口**：`/chat/service`

### 2. 游戏对话
- **功能**：基于世界状态的游戏剧情推进
- **特点**：沉浸式的游戏交互体验
- **入口**：`/chat/game`

### 3. 情景陪伴
- **功能**：理解用户感受，提供情感支持和陪伴
- **特点**：成为用户的心灵伙伴
- **入口**：`/chat/companion`

## 核心能力

1. **情绪识别**：实时分析用户情绪，提供相应的情感回应
2. **三层记忆**：核心记忆、事件记忆、工作记忆，构建完整的记忆体系
3. **世界状态**：模拟真实世界状态，影响 Agent 的行为和决策
4. **主动交互**：基于世界状态和用户情绪，主动发起有意义的对话
5. **可观测追踪**：完整的行为追踪和决策过程可视化，提高系统透明度

## 前端页面结构

### 1. 首页 (`/`)
- 顶部品牌区：项目名 + 一句话定位
- 中间主视觉区：大标题 + 副标题 + 两个按钮（进入演示、查看架构）
- 三场景卡片区：客服场景、游戏对话、情景陪伴
- 能力亮点区：情绪识别、三层记忆、世界状态、主动交互、可观测追踪
- 底部演示说明区：当前版本支持内容、后续接后端计划

### 2. 聊天工作台 (`/chat/:scene`)
- 顶部：场景切换条（客服、游戏、情景陪伴）
- 左中：聊天主区（消息列表、输入区）
- 右侧：状态/记忆/追踪面板（情绪状态、世界状态、主动交互、记忆摘要、决策摘要）

### 3. 记忆管理 (`/memory`)
- 技术展示页，展示三层记忆系统的管理界面
- 包含核心记忆、事件记忆、工作记忆三个标签页
- 支持添加核心记忆

### 4. 开发设置 (`/settings`)
- 基本设置：主题、字体大小、主动消息开关
- 高级设置（折叠面板）：LLM 提供商、API 密钥、模型名称、世界状态更新、NPC 系统

## 技术栈

- **前端**：React + TypeScript + Vite + Tailwind CSS + Zustand + React Router
- **状态管理**：Zustand
- **路由**：React Router
- **样式**：Tailwind CSS
- **图标**：Lucide React

## 启动方式

### 前端启动

1. 安装依赖
   ```bash
   npm install
   ```

2. 启动开发服务器
   ```bash
   npm run dev
   ```

3. 构建生产版本
   ```bash
   npm run build
   ```

### 后端启动

后端代码位于项目根目录，使用 Python 实现。

1. 安装依赖
   ```bash
   pip install -r requirements.txt
   ```
